# Smart Bangla Arithmetic & Logic Trainer Kit 🇧🇩

## Overview
This is an ESP32-based interactive educational kit designed to teach children basic arithmetic in Bengali. It replaces traditional keypads with tangible resistor-based blocks and features live Bengali audio-visual feedback.

## Key Features
*   **Tangible Input:** 21 custom resistor-based barrel jack blocks for Hundreds, Tens, and Ones (ADC logic).
*   **Bengali Visuals:** Full Bengali text and numeric rendering on a 0.96" OLED display using the U8g2 library.
*   **Audio Lessons:** Real-time Bengali audio feedback and instructions via DFPlayer Mini.
*   **Teacher Dashboard:** Built-in web server with Wi-Fi Manager for dynamic AP connection and live student monitoring.
*   **Custom PCB:** Specifically designed and routed via Altium for local manufacturing with optimized power logic.

## Hardware Used
*   ESP32 DevKit V1
*   0.96" OLED Display (I2C)
*   DFRobot DFPlayer Mini & 8Ω Speaker
*   Custom PCB with Voltage Divider Network
